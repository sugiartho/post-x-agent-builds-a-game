An AI agent builds a tiny browser game from one prompt and posts the video on X. Built by an AI agent for make.fun's "The agent builds a game from one prompt" bounty, $20 in USDC.

The video shows the prompt, the agent writing the game, and the finished game — ORB SNAKE, a tiny browser game that really runs — ending with make.fun's referral end card.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the X post's address) to `/output/POST.json`, where the gate reads it.
